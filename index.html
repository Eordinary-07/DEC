UNIT I • Kumar Ch. 4, Fig. 4.2 (p. 165)

Standard TTL NAND Gate with Totem-Pole Output

Hardware Explanation: Multi-emitter BJT $Q_1$ performs input logic. When all inputs are HIGH, current enters base of phase-splitter $Q_2$, saturating it. This pulls the base of pull-up $Q_4$ LOW while driving pull-down $Q_3$ ON, snapping the physical output wire to $V_{OL} \approx 0.2\text{ V}$. Diode $D_1$ prevents $Q_4$ and $Q_3$ from conducting simultaneously.

UNIT I • Kumar Ch. 4, Fig. 4.31 (p. 195)

CMOS 2-Input NAND Gate Circuit

Hardware Explanation: Two PMOS transistors ($Q_1, Q_2$) are in parallel between $V_{DD}$ and output, while two NMOS transistors ($Q_3, Q_4$) are in series to Ground. If either input is LOW, at least one PMOS turns ON and NMOS is cut off, holding output at $5.0\text{ V}$ with zero static DC current.

UNIT III • Kumar Ch. 6, Fig. 6.8 (p. 327)

4-Bit Parallel Binary Adder/Subtractor with Controlled Inverters

Hardware Explanation: The mode signal $M$ controls XOR gates: when $M=0$, $B \oplus 0 = B$ and $C_0=0$ (true addition $A+B$). When $M=1$, $B \oplus 1 = \overline{B}$ and $C_0=1$ (2's complement subtraction $A + \overline{B} + 1 = A - B$) using identical full adder hardware.

UNIT IV • Kumar Ch. 10, Fig. 10.12 (p. 565)

Master-Slave JK Flip-Flop Circuit

Hardware Explanation: When CLK is HIGH, the master latch samples inputs $J$ and $K$ while the slave is disabled. When CLK transitions LOW, master inputs disable and the inverter enables the slave latch to transfer state to output $Q$. Feedback oscillation is physically impossible.

UNIT V • Kumar Ch. 17, Fig. 17.5 (p. 947)

R-2R Ladder Digital-to-Analog Converter

Hardware Explanation: Looking into any ladder node to the left, equivalent resistance is always $R$. Current arriving at each node splits exactly $50\% / 50\%$, generating binary weighted currents $I/2, I/4, I/8, I/16$ into the op-amp summing bus using only TWO resistor values ($R$ and $2R$).

UNIT V • Kumar Ch. 17, Fig. 17.23 (p. 964)

Dual-Slope Integrating ADC Architecture

Hardware Explanation: Integrates $V_{in}$ for fixed time $T_1$, then de-integrates reference $-V_{ref}$ for variable time $T_2$. Because both phases share the same $RC$ network, $R$ and $C$ cancel out: $V_{in} = V_{ref}(T_2 / T_1)$, making measurement independent of component tolerances.
